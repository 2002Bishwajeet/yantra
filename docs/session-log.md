- **2026-07-31 (cont.)** — **Y-061 done: `yantra logs <name>`.** The task said "tail the transcript JSONL", and measuring one first changed the design: **a real 14 MB transcript is an application journal, not a log** — 6,815 records across 13 `type`s, of which `user` and `assistant` are the only two anyone reads, and most `user` records are tool *results*, which are the agent's input and the bulk of the bytes (**I-46**). A literal tail would have shipped megabytes to show `queue-operation` and `file-history-snapshot`. So selection happens on the far side with `grep`, `-n` counts *turns* rather than records, and what crosses the wire is projected down to who spoke, what they said, and which tools they called. **This is the one M3 task Y-059 does not gate** — `logs` never runs `claude`, it reads a file, so the container and the real Mac can both test it fully. Q12's requirement is now a committed test rather than a note: `a_transcript_that_is_still_being_written_reports_a_moving_mtime` asserts the mtime *moved*, because #70632's failure mode is a transcript that exists and stopped growing, which every existence check calls healthy. Both timestamps are taken from the far side's clock, so what is reported is an age rather than the drift between two machines. **Found I-45 by running it on macOS rather than trusting the container**: `stat -c %Y` is GNU-only and macOS answers `illegal option`, so the `stat -f %m` fallback is load-bearing — and Alpine accepts the GNU spelling, so CI would have stayed green forever while the Mac failed.
