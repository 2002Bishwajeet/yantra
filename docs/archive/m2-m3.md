| Y-062 | `yantra down <name>` | ✅ done | claude | Y-063, Y-046 | **Stacked on Y-063, and the order is the design.** The exit status lives in the pane (I-4) and `kill-session` destroys the pane, so how the agent ended can only be read *before* it is stopped — a `down` that killed first would have nothing left to report, and the container test asserts exactly that rather than only that the session is gone. Sends `SIGTERM` first and waits for the process to go, which is what earns the `Stopped` verdict: Claude Code runs its `SessionEnd` hooks on that signal and exits 143, and a `kill-session` alone would have produced a `Killed` with nothing of the agent's own run. The wait is bounded and happens **on the far side** — `kill -0` in a loop, so a fast shutdown costs one round trip and a process that ignores the signal is stopped anyway rather than hanging `down` forever. **This is Y-046's answer**, tested as such: the pane's pid is confirmed gone afterwards, which killing the local `ssh` never achieved (I-27). | Y-063 | Tell "finished" from "crashed" | ✅ done | claude | Y-060 | `yantra_core::status` and `yantra status <name>`, reading two sources exactly as R-2 argues: the pane, and `claude agents --json`. **The design earned itself immediately** — measuring tmux produced **I-47**, a second instance of R-2's shape that has nothing to do with agents: a signal-killed pane leaves `pane_dead_status` **empty**, so anything that parses it and defaults a missing value to 0 reports a `kill -9` as *finished*. Confirmed identical on 3.5a and 3.7b, the two versions this fleet runs. Six verdicts, each one a thing someone can act on: `NoSession`, `Running`, `Finished` (0), `Stopped` (143 — SIGTERM **handled**, so `SessionEnd` hooks ran), `Crashed`, `Killed` (signal **unhandled**, so nothing ran). Where the sources contradict each other the answer is `Unclear` **with its reason attached**, never a guess: a live pane with no registry entry is precisely R-2's silent death, and `is_running()` is false there because an unknown answer must not read as a yes. A machine with no usable `claude` is still answered from the pane — a missing second opinion is not a contradiction. 6 container tests that *produce* the endings rather than describing them (a real `exit 143`, a real `kill -9`), 9 unit + 1 CLI. **`signal` is a name, not a number** — see I-48, found when `down` met a real Mac. |
