# v0.5.0 — the owner's pass on the real fleet

**Owner's ask, 2026-10-06 (Y-438).** Every row in v0.5.0 passed its tests, a review and CI. Those
tests ran in containers. This pass checks the things a container cannot prove: your voice, your
logins, your transcripts, and your phone.

It takes 30 to 45 minutes. Walk it in order.

- `[x]` it works.
- `[ ]` you did not get to it.
- `[!]` it is wrong. Write one line in §7 and keep going. Do not stop to fix it.

Each section ends with a **Feel** line: 1 to 5, and one sentence.

## 0. Before you start

- [ ] Update the appliance: Settings → About → *Update to v0.5.0*, or `sudo yantra update` on the box.
- [ ] `yantra --version` on the box says **0.5.0**.
- [ ] On each machine you use, run `install.sh` or copy the new `yantra` there, as before.

## 1. The chat (Y-356, Y-359)

- [ ] Open a workspace and the Chat tab. The status line says the chat runs in its own worktree.
- [ ] Ask for a small change. The answer streams in, with tool cards.
- [ ] When Claude asks to run a tool, the permission card shows. Accept works, and Decline works.
- [ ] Send a long task, open the Terminal tab, then go back to Chat. **The turn is still running.**
- [ ] Press Stop during a turn. The turn ends and says it was stopped.
- [ ] The terminal session's repository has no change from the chat. The chat's changes are in its
      own worktree under `~/.yantra/worktrees/chat/`.
- [ ] Reload the page. The chat shows the same conversation.

**Feel:** _/5 —

## 2. Delegation to other agents (Y-433, Y-435)

Do this on a machine where Codex, Gemini, Grok or opencode is installed and logged in.

- [ ] Add the server to Claude Code: `claude mcp add yantra -- yantra mcp --daemon <dashboard URL>`.
- [ ] In Claude, ask it to give a small task to one of those agents. Claude calls `start_task`.
- [ ] `task_status` shows the task's state, its last message and a summary of changed files.
- [ ] The task works in its own worktree under `~/.yantra/worktrees/`, not in your repository.
- [ ] `remove_task` deletes the worktree and its branch.
- [ ] An agent that is not logged in fails with a clear message, not a hang.

**Feel:** _/5 —

## 3. The microphone (Y-417, Y-418, Y-419)

Use one Linux machine with PipeWire.

- [ ] On its Readiness card, tick **Microphone** and press Install. Or run `yantra install <machine> --mic`.
- [ ] If sudo asks for a password, the card shows the command to run. Run it, then Install again.
- [ ] `yantra doctor <machine>` shows the mic as present. Log out of that machine, then check again.
      **It is still present.**
- [ ] On your phone, open a session on that machine. Hold **Hold to talk** and speak. Claude hears it.
- [ ] On Safari, check the first hold after a page load. It records.
- [ ] From a Linux laptop, run `yantra mic <machine>`, speak, then press Ctrl-C. Claude hears it.

**Feel:** _/5 —
