# v0.8.0 — the owner's pass on the real fleet

**Owner's ask, 2026-10-06 (Y-438), carried into v0.6.0 (Y-450), v0.7.0 (Y-455), v0.7.1 (Y-457), v0.7.2 (Y-459) and v0.8.0 (Y-548).** Every row in
v0.5.0 to v0.8.0 passed its tests, a review and CI. Those
tests ran in containers. This pass checks the things a container cannot prove: your voice, your
logins, your transcripts, and your phone.

It takes 90 to 110 minutes. §1d, §1e, §2b and §6b are new in v0.7.0, and §6c is new in v0.7.1 and v0.7.2. §0b and §6d to §6j are new in v0.8.0. Walk it in order.

- `[x]` it works.
- `[ ]` you did not get to it.
- `[!]` it is wrong. Write one line in §7 and keep going. Do not stop to fix it.

Each section ends with a **Feel** line: 1 to 5, and one sentence.

## 0. Before you start

- [ ] Update the appliance: Settings → About → *Update to v0.8.0*, or `sudo yantra update` on the box.
- [ ] `yantra --version` on the box says **0.8.0**.
- [ ] On each machine you use, run `install.sh` or copy the new `yantra` there, as before.

## 0b. Install and Setup (Y-473, Y-474, Y-475, Y-477, Y-478)

- [ ] Run `install.sh` on a spare Debian 13 box with no curl, using the `wget` form in `docs/appliance.md`. The script installs curl and goes on.
- [ ] Run `install.sh --yes` with `TS_AUTHKEY` set and no terminal. It asks nothing and ends on the dashboard URL.
- [ ] Run `install.sh` at a terminal on a box that has `qrencode`. It ends on a QR code of the dashboard URL. Scan it with the phone: the dashboard opens.
- [ ] Run `install.sh` again at a terminal. It asks *Restart yantrad and yantra-agent now? [Y/n]*. Answer n, and nothing restarts. Run it once more and answer y: both units restart.
- [ ] Open Setup with two or more machines. **Check all** checks every unchecked machine with one press. **Install on all** installs on every checked machine that lacks an install.
- [ ] If the appliance's Tailscale key expires within 30 days, Setup shows a step with the date and a link to the admin console. If key expiry is off, no step shows.
