## What is good

1. The token file is R14 verbatim: fifteen roles plus emphasized, ten shape steps, four `linear()`
   springs with their settle times, state-layer and focus-ring numbers, and `tokens.test.ts` diffs it
   against `palette-sage.json` so a drifted hex fails a test.
2. Every failure the daemon can produce has one typed shape: `fetchJson` → five `Kind`s, `look` →
   data, `errors.test.ts` proves every exported query rejects with `ApiError` or resolves a failed
