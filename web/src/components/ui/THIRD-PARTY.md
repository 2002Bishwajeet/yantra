# Third-party code in this directory

## T3 Code

Fifteen files here were copied near-verbatim from **[T3 Code](https://github.com/pingdotgg/t3code)**,
which is MIT-licensed. Each carries a header naming this file.

- **Upstream:** <https://github.com/pingdotgg/t3code>
- **Path:** `apps/web/src/components/ui/`
- **Commit taken from:** `963ebf5b` ("ci: label-gated hosted-web preview deploys (#5465)")
- **Taken on:** 2026-08-09, by [Y-164](../../../../tracker.md#3-task-board)

`button.tsx` · `collapsible.tsx` · `field.tsx` · `form.tsx` · `input.tsx` · `kbd.tsx` ·
`label.tsx` · `popover.tsx` · `scroll-area.tsx` · `separator.tsx` · `skeleton.tsx` ·
`switch.tsx` · `toggle.tsx` · `toggle-group.tsx` · `tooltip.tsx`

The only edit is the import alias — T3 Code's is `~/`, Yantra's is `@/`. Everything else, including
T3's own class strings and `data-slot` names, is upstream's.

`alert.tsx`, `badge.tsx`, `card.tsx`, `empty.tsx` and `table.tsx` are **not** from T3 Code. They are
[shadcn/ui](https://ui.shadcn.com) output, generated by the CLI against `web/components.json`.

### What was deliberately not taken

[D1 §7](../../../../docs/design/01-dashboard.md#7-component-vocabulary) refuses T3 Code's Effect
runtime, zustand, Clerk, its `libghostty-vt` terminal, its `packages/ssh` and its
`native/resource-monitor`. None of the files above touch any of them.

Seven more from D1 §7's take list — `dialog`, `sheet`, `menu`, `select`, `combobox`, `command`,
`spinner` — import `lucide-react`, which this repo does not depend on. They wait on that package.
