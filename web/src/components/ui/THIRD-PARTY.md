# Third-party code in this directory

## T3 Code

Twenty-four files here were copied near-verbatim from
**[T3 Code](https://github.com/pingdotgg/t3code)**, which is MIT-licensed. Each carries a header
naming this file.

- **Upstream:** <https://github.com/pingdotgg/t3code>
- **Path:** `apps/web/src/components/ui/`
- **Commit taken from:** `963ebf5b` ("ci: label-gated hosted-web preview deploys (#5465)")
- **Taken on:** 2026-08-09, by [Y-164](../../../../tracker.md#3-task-board) (fifteen) and
  [Y-166](../../../../tracker.md#3-task-board) (nine)

`autocomplete.tsx` · `button.tsx` · `collapsible.tsx` · `combobox.tsx` · `command.tsx` ·
`dialog.tsx` · `dialog-styles.ts` · `field.tsx` · `form.tsx` · `input.tsx` · `kbd.tsx` ·
`label.tsx` · `menu.tsx` · `popover.tsx` · `scroll-area.tsx` · `select.tsx` · `separator.tsx` ·
`sheet.tsx` · `skeleton.tsx` · `spinner.tsx` · `switch.tsx` · `toggle.tsx` · `toggle-group.tsx` ·
`tooltip.tsx`

`autocomplete.tsx` and `dialog-styles.ts` are not on D1 §7's take list; `command.tsx` imports the
first and `command.tsx`/`dialog.tsx` the second.

The only edit is the import alias — T3 Code's is `~/`, Yantra's is `@/`. Everything else, including
T3's own class strings and `data-slot` names, is upstream's.

Three of T3's CSS classes came with them, into
[`web/src/index.css`](../../index.css) rather than here: `.dialog-glass`, `.dialog-backdrop` and
`.dropdown-glass`. A popup with no rule behind those names has no background at all.

`alert.tsx`, `badge.tsx`, `card.tsx`, `empty.tsx` and `table.tsx` are **not** from T3 Code. They are
[shadcn/ui](https://ui.shadcn.com) output, generated by the CLI against `web/components.json`.
